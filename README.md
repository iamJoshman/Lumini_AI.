# Lumina AI

Lumina AI is a futuristic AI tools directory website built with HTML, CSS, and JavaScript.

## Features

- Cyberpunk neon UI
- Responsive design
- AI tools showcase
- Search filtering
- Typing animation
- Modern glassmorphism effects
- AI awareness section

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Live AI Tools Included

- ChatGPT
- Claude AI
- Canva AI
- GitHub Copilot
- Runway ML
- ElevenLabs

## Purpose

Lumina AI was created to help users discover useful AI tools while encouraging people to see AI as a technology that assists humans rather than replacing them.
